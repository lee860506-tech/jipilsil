# 집필실 · 쓰는 오늘, 완성의 내일로

한 문장씩, 이야기가 된다 ♡ — 초안부터 재독까지, 나만의 창작 메이트.
웹소설 작가를 위한 개인 집필 노트 (설치형 웹앱 · PWA). 서버 없이 기기 안(IndexedDB)에 저장하고, 원하면 내 구글 드라이브에 동기화해요.

- 실행: <https://lee860506-tech.github.io/jipilsil/>
- 드라이브 연결 방법: [DRIVE_SETUP.md](DRIVE_SETUP.md)
- 폰: 크롬에서 열고 ⋮ → **홈 화면에 추가 / 앱 설치**, 또는 안드로이드 앱 [jipilsil.apk](https://github.com/lee860506-tech/jipilsil/releases/latest/download/jipilsil.apk) (크롬 기반 TWA · 구글 로그인 가능)
- PC: 크롬·엣지 주소창의 설치 아이콘 ⊕ → 설치

## 기능
- 홈 / 작품 / 노트 / 보관함 / 마이 탭, 시작 화면
- 작품 → 회차 (순서 바꾸기, 이름, 회차 메모), 작품 전체 검색
- 방해 없는 에디터: 긴 붙여넣기, 글자수(공백 포함/제외)·단어수, 글자 크기, 낮/밤/세피아, 집중 모드, 고운바탕 서체
- 자동 저장(몇 초마다·창 벗어날 때), 오프라인 동작, 저장 상태 🟢🟡🔴
- 수정 기록: 몇 분마다 자동 + 직접 버전 저장, 비교(diff), 되돌리기
- 오늘의 집필(하루 목표), 연속 집필, 집필 타이머(뽀모도로), 북마크
- 작품별 **회차 목록표**(번호·제목·글자수·상태·한줄 메모·마지막 수정·드라이브 상태, 정렬, 합계)와 **인물·설정표**, CSV 내보내기
- **아이디어 사진함**: 사진 찍기·갤러리·붙여넣기, 설명·태그·작품/회차 연결, 기기에서 압축(긴 변 1600px)
- 음성 입력(받아쓰기, ko-KR), 낭독 듣기(목소리·속도·대사 다른 목소리), 음성 메모 녹음
- 내보내기 TXT / DOCX / 작품 전체 ZIP, TXT 가져오기(여러 개, 파일 이름에서 회차 번호, UTF-8/CP949)
- 구글 드라이브(drive.file 권한만): `집필실/<작품>/01화` 구글 문서, 목록표·인물·설정표 구글 시트, `음성메모/`, `아이디어 사진/` 폴더, 다른 기기 변경 받아오기, 충돌 시 선택(이 기기 / 드라이브 / 둘 다), 오프라인 대기열
