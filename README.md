# 집필실 · 쓰는 오늘, 완성의 내일로

한 문장씩, 이야기가 된다 ♡ — 소설·웹소설 작가를 위한 집필 노트 (설치형 웹앱 · PWA).
서버가 없어요. 원고는 **내 기기(IndexedDB)** 에 먼저 저장되고, 원하면 **내 구글 드라이브**에 동기화돼요. 처음 열면 빈 집필실로 시작해요.

## 바로 쓰기
- 주소: <https://lee860506-tech.github.io/jipilsil/>
- 다른 사람과 공유: 주소만 보내면 돼요. 각자의 원고는 각자 기기·드라이브에만 저장돼서 서로 보이지 않아요. (앱 **마이 → 다른 사람과 공유**)
- ⚠ 구글 드라이브 연결: 위 주소의 기본 로그인 설정(OAuth)은 운영자가 허락한 계정만 쓸 수 있을 수 있어요. 「액세스 차단됨 / 403 access_denied」가 나오면 아래 「드라이브 연결」처럼 **내 클라이언트 ID**를 만들어 넣거나, 드라이브 없이 기기 저장 + **설정 → 전체 백업 ZIP**으로 써요.

## 앱으로 설치하기
- **PC (크롬·엣지)**: 주소창 오른쪽 설치 아이콘 ⊕ → **설치**. 시작 메뉴·바탕화면에서 앱처럼 열려요.
- **안드로이드 (크롬)**: ⋮ 메뉴 → **홈 화면에 추가 / 앱 설치**.
- **아이폰·아이패드 (Safari)**: 아래 공유 버튼 ⬆︎ → **홈 화면에 추가**.
- 설치하면 오프라인에서도 열리고, 브라우저가 저장 공간을 함부로 지우지 않아요.

## 드라이브 연결 (내 클라이언트 ID)
1. [DRIVE_SETUP.md](DRIVE_SETUP.md) 를 따라 구글 클라우드에서 **웹 애플리케이션 클라이언트 ID**를 만들어요 (무료, 약 10분). 권한은 `drive.file`(앱이 만든 파일만)뿐이에요.
2. 「승인된 자바스크립트 원본」에 앱을 여는 사이트 주소(예: `https://<아이디>.github.io`)를 넣어요.
3. 앱 **마이 → 집필 설정 · 백업 → OAuth 클라이언트 ID** 칸에 붙여 넣고 **구글 드라이브 연결**. 이 값은 그 기기에 저장되고 기본값보다 우선해요.
4. 동의 화면이 **테스트 중**이면 「테스트 사용자」에 넣은 계정만 로그인돼요. 여러 사람이 쓰게 하려면 **앱 게시(프로덕션)** 로 바꿔요.

## 직접 배포하기 (포크 + GitHub Pages)
1. 이 저장소 오른쪽 위 **Fork**.
2. 내 저장소 **Settings → Actions → General** 에서 워크플로 실행을 허용하고, **Actions** 탭에서 `deploy-pages` 를 한 번 **Run workflow** 해요. (main 에 올릴 때마다 자동으로 `gh-pages` 브랜치에 빌드돼요.)
3. **Settings → Pages → Source: Deploy from a branch → `gh-pages` / (root)** → 저장. 잠시 후 `https://<아이디>.github.io/jipilsil/` 에서 열려요.
4. `config.js` 를 내 것으로 고쳐요.
   - `DEFAULT_CLIENT_ID`: 내 클라이언트 ID (비워 두면 사용자가 설정에서 넣어요). 원본의 기본 ID는 원본 주소에서만 쓰이게 되어 있어요.
   - `REPO`: `내아이디/jipilsil` (안내 링크·ZIP 주소)
   - `OWNER_HOST`, `LEGACY_PEN_NAME`: 원본 운영자용이에요. 내 주소로 바꾸거나 그대로 둬도 돼요(포크 주소에선 꺼져요).
5. 마스코트 그림(`img-b64/`)은 MIT에 포함되지 않아요 — 다시 배포할 땐 내 그림으로 바꿔 주세요 (base64 로 넣은 `.webp`).
- 서버 없이 **정적 파일만** 있으면 어디서든 돼요: [릴리스 ZIP](https://github.com/lee860506-tech/jipilsil/releases) (`jipilsil-web.zip`) 을 받아 아무 정적 호스팅(Netlify, Cloudflare Pages, 내 서버)에 올려도 돼요. 내 컴퓨터에서는 `python3 -m http.server 8000` 후 <http://localhost:8000>.
- 안드로이드 APK(`android/`)는 원본 주소 전용 TWA예요. 내 주소용으로 만들려면 `android/twa-manifest.json` 의 host·packageId를 바꾸고 Bubblewrap으로 빌드한 뒤, 사이트 루트에 `/.well-known/assetlinks.json` 을 올려야 해요.

## 기능
- 홈 / 작품 / 노트 / 보관함 / 마이, 필명 설정(인사말)
- 작품 → 회차, 전체 검색, 방해 없는 에디터(글자수·원고지 매수, 테마, 집중 모드)
- 자동 저장, 오프라인, 수정 기록(자동·직접 버전, 비교, 되돌리기), ChatGPT용 복사·수정본 안전 반영
- 회차 목록표·인물·설정표(CSV), 아이디어 사진함, 북마크, 음성 메모
- **설계 노트**: 소스(출처·링크·인용) · 아이디어 · 시퀀스(장면 순서), 원고에서 💡 바로 적기
- 받아쓰기·낭독, TXT/DOCX/ZIP 내보내기, TXT 가져오기
- 구글 드라이브(drive.file): 회차는 구글 문서, 표는 구글 시트, 충돌 시 덮어쓰지 않고 선택

## 개인정보
원고·사진·음성은 **내 기기와 내 구글 드라이브에만** 저장돼요. 이 저장소·사이트에는 앱 코드만 있어요. 클라이언트 보안 비밀은 쓰지 않아요.
